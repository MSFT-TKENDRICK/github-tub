Discover and manage agent activity with new session filters
GitHub Enterprise AI Controls and agent control plane now includes additional session filters, making it easier to discover and manage agent activity across your enterprise.
What’s new 
In addition to searching for agentic session activity by agents and by organizations within your enterprise, we’ve now rolled out the following filters:
Status : Search for session by status, such as queued, in progress, completed, failed, idle waiting for user, timed out, and cancelled.
Repository : Search for sessions by the repository where the agent session occurred.
User : Search for sessions by the user who initiated the agent session.
To learn more, see our documentation on AI controls and the agent control plane .
