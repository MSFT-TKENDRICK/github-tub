View and manage agent sessions from issues and projects

What's new 
Additional improvements 
You can now view and steer cloud agent sessions directly from issues and projects, giving you better visibility into agent activity without leaving your workflow.
What’s new 
Session pill on issues: A new header pill on issues shows all active and completed agent sessions at a glance.
Session side panel on issues: Click any session from the pill or assignee area to open it in the sidebar, where you can view progress, review logs, or steer the agent.
Agent sessions enabled by default in projects: “Show agent sessions” is now enabled by default for both new and existing project views, so you can see agent activity without any additional configuration.
Session side panel in projects: Click on an agent session from your project board to open it directly in the sidebar. View session details, check progress, or provide guidance to the agent without navigating away from your project.
Join the discussion within GitHub Community .
Additional improvements 
Smarter label suggestions: The label picker now remembers your most frequently used labels and surfaces them at the top, so you can apply labels faster without searching.
