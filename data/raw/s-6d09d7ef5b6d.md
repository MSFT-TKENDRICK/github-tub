GitHub Copilot SDK is becoming Microsoft Copilot SDK
We’re transitioning GitHub Copilot SDK to Microsoft Copilot SDK .
What began as the SDK for the GitHub Copilot harness is becoming the programmable interface for the Microsoft Copilot harness , the shared agent foundation used across Microsoft and GitHub products. This evolution reflects our broader goal to enable developers to build and customize agent experiences using the same core foundation that powers our own products, while retaining control over their prompts, tools, policies, and application experiences.
As part of this transition, we have begun updating the SDK repository to reflect the upcoming move to the Microsoft organization and begun updating branding and documentation. The migration will happen in phases, so existing package names, namespaces, and some documentation may continue to reference GitHub Copilot SDK during the transition.
This announcement is to share the SDK’s direction and expanded role. No immediate changes are required for existing users.
Support for the Copilot SDK remains the same. For more information: copilot-sdk/SUPPORT.md
