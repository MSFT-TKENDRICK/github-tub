Close all open contributions authored by a blocked user
You can now automatically close all open issues, discussions, and pull requests authored by a user when you block them from your personal account or organization.
To use this option, select Close content authored by this user in the block dialog. You’ll see it whenever you block a user, including from an issue or pull request comment, or from Settings → Moderation → Blocked users .
