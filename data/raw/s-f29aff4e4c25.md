Key benefits 
You can now use GitHub’s Copilot usage metrics APIs to better understand how Copilot influences pull request outcomes across your organization, from review suggestions to merged pull requests.
Editor’s note (March 19, 2026): Corrected the broken link. 
How it works 
New enterprise-level API metrics cover pull request review suggestions and acceptance, pull requests created with Copilot coding agent that got merged, and pull request cycle time.
Who can use this feature 
Customers who have enabled Copilot usage metrics and are either the enterprise admin or have the View Enterprise Copilot Metrics role.
Key benefits 
Gain visibility into how Copilot is helping author pull requests
Track whether Copilot helps teams shorten the time between idea to a merged pull request
Measure how Copilot’s review suggestions turn into real changes
