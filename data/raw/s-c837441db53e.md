Copilot usage metrics now includes organization-level GitHub Copilot CLI activity
Following our enterprise-level release and our user-level release of CLI telemetry, we’re completing coverage with organization-level support.
Organization admins can now view CLI-specific activity and usage totals in their 1-day and 28-day reports. You can learn more in our documentation about Copilot usage metrics . This includes:
Daily active CLI users.
CLI session and request counts.
Token usage totals, including average tokens per request.
Why this matters 
Track CLI adoption across your organization alongside existing IDE metrics.
Understand how teams are using Copilot from the command line with session volume and request counts.
Use token usage breakdowns to monitor consumption trends and plan for expanded rollout.
Visit our API documentation to learn more. Join the discussion within GitHub Community .
