GitHub Copilot in VS Code (1.140 release) 
This week, put Copilot to work with new models, reusable workflows and desktop app automation, plus Azure canvases and VS Code improvements.
GitHub Copilot 
Claude Sonnet 5.5 is available to Copilot Pro, Pro+, Max, Business, and Enterprise users. 
GPT-6.1 Sol is available to Copilot Pro+, Max, Business, and Enterprise users.
Let Copilot select and coordinate models for your task with HydraFusion , a research preview now available in VS Code and the GitHub Copilot app alongside Copilot CLI. Clearer, more frequent progress updates help you follow its work.
Save a process for Copilot to follow again. With dynamic workflows, you can ask Copilot to run release checks, investigate failures, and pause for your review, then reuse that workflow next time. Describe the steps and ask Copilot to build it, or write it yourself in code. Now in public preview in Copilot CLI, the Copilot app, and the Copilot SDK. Learn more about dynamic workflows .
Automate tasks in desktop apps with computer use in Copilot CLI and the Copilot app, now in public preview on macOS and Windows. Copilot can navigate apps, edit content, and move information across workflows, even in software without an API or command-line interface. You stay in control with approval before Copilot controls an app. Learn more about computer use .
GitHub Copilot app 
Explore Azure resources, understand costs, and build automated workflows alongside Copilot. Three new Azure canvases bring resource queries, cost health checks, and Azure Functions hosted skills into interactive workspaces in the Copilot app. Install them from the Awesome Copilot marketplace under Customize > Plugins .
GitHub Copilot in VS Code (1.140 release) 
Work across multiple folders in a single agent session with multi-folder sessions, now experimental.
Skip repeated dependency installs and reduce duplicated artifacts by reusing ignored folders across worktrees, now experimental.
Explore everything that’s new in the full release notes .
