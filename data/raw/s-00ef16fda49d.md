1 minute read 
Accessibility statements highlighted on repository overview
You can now find an ACCESSIBILITY.md file in your repository’s root, the .github/ directory, or the docs/ directory highlighted on the repository overview. You can also add or propose an accessibility statement from a public repository’s Community Standards page.
This improvement is available on all GitHub plans on github.com and will be available in GitHub Enterprise Server 3.24.
For more information, see Adding an accessibility page to your repository .
