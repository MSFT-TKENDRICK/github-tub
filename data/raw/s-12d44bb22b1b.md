GPT-5.4 mini is now available in Copilot Student auto model selection
GPT-5.4 mini is now generally available to Copilot Student plan via Copilot auto model selection .
This model is part of Auto in GitHub Copilot Chat on Visual Studio Code, Visual Studio, JetBrains IDEs, Xcode, and Eclipse.
To learn more about the models available in Copilot, see our documentation on models and get started with Copilot today.
