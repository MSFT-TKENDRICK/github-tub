Organization-level enablement for GitHub Code Quality
Table of Contents

What's new 
Who this is for 
Availability 
Organization administrators can now enable or disable GitHub Code Quality across all repositories in their organization with a single toggle, instead of configuring each repository individually.
What’s new 
A new “Code quality” section is available in your organization settings under Security . From this page, you can turn GitHub Code Quality on or off for all existing repositories in your organization in one action.
Who this is for 
Organization administrators on GitHub Enterprise Cloud and GitHub Team plans who want to quickly roll out Code Quality across their organization.
Availability 
This feature is available in public preview for GitHub Enterprise Cloud and GitHub Team plans. GitHub Code Quality is not available on GitHub Enterprise Server.
For more information, see our docs about GitHub Code Quality .
