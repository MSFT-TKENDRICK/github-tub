What's new for Business and Enterprise

Learn more 
Following the rollout to Copilot Pro and Pro+ users , Copilot Memory is rolling out user-level preferences in public preview for Copilot Business and Copilot Enterprise, with new admin controls for governance.
Copilot Memory can now capture user-level preferences such as communication style, tool stack, or git conventions, applying them across repositories and Copilot experiences. These user-level preferences complement existing repository-level facts, which are applied to all collaborators but scoped to a single repository.
What’s new for Business and Enterprise 
Admin policy : The existing Copilot Memory policy now applies to user-level preferences too. This policy is disabled by default, but user-level preferences will be automatically enabled if you have already enabled the existing policy.
Export for auditing : Admins can export user-level preferences captured by Copilot Memory under their Copilot license.
Bulk delete : Admins can bulk delete user-level preferences captured by Copilot Memory under their Copilot license.
User opt-out : Individual users can opt out at any time from their personal Copilot settings .
Billing-entity isolation : All information stored by Copilot Memory remains scoped to the billing entity under which it was generated.
Availability 
User-level preferences are available in public preview across Copilot coding agent and Copilot CLI.
