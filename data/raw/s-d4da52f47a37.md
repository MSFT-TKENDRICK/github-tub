Start a GitHub Advanced Security trial from a risk assessment
Eligible enterprise admins can now start a GitHub Advanced Security trial directly from the Secret Protection or Code Security risk assessment to start evaluating the products faster. If you aren’t eligible for a self-serve trial, Secret Protection and Code Security can still be enabled directly from the risk assessment or you can talk to someone at GitHub .
To learn more, see our docs about self-serve GitHub Advanced Security trials .
