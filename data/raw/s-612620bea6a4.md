Upcoming GHES change impacting uploading support bundles
We want to give you advance notice of an upcoming security change that may affect GitHub Enterprise Server (GHES) support bundle uploads.
Beginning August 18, 2026, GitHub will start rejecting command-line support bundle uploads from older GHES appliances that have not been updated with the required security patches.
To avoid any disruption when submitting support bundles with ghe-support-bundle , ghe-cluster-support-bundle , or ghe-support-upload commands, please update your GHES instance to the latest patch release available for your current version line. At minimum, the required patch versions are:
3.21.3 
3.20.5 
3.19.9 
3.18.12 
3.17.18 
If your instance is running a GHES version that is no longer supported, we strongly recommend upgrading to a supported version as soon as possible.
If you’re unable to update to the required patch version before August 18, 2026, and need to upload a support bundle, please contact GitHub Support so we can help you with next steps.
