Monitor Copilot coding agent logs live in Raycast
Raycast is a powerful free launcher for macOS and Windows. It can launch apps, search files, control your system, and leverage community-built extensions.
With the GitHub Copilot extension for Raycast , you can hand tasks to Copilot coding agent , our cloud-based background agent, and track progress from anywhere.
Now, you can watch Copilot’s logs live from Raycast without jumping to GitHub, so you can keep an eye on what Copilot is doing and track progress with just a few keyboard strokes.
To watch Copilot’s logs live, install the extension, open Raycast, select the View Tasks command, then pick your session from the list.
Copilot coding agent is available to Copilot Pro, Copilot Pro+, Copilot Business, and Copilot Enterprise subscribers. If you’re a Copilot Business or Copilot Enterprise subscriber, an administrator will have to enable Copilot coding agent from the “Policies” page before you can use it.
