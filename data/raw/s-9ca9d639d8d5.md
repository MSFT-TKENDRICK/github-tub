Update (October 28, 2026): The Moderate role feature is not yet available. 
The Moderate role will be available in the coming weeks. 
We’ve introduced a new Moderate role that allows you to moderate and edit issues without granting access to code.
Below are the actions you can perform with the Moderate role.
Content editing 
Edit issues you didn’t author, including issue titles, bodies, and comments
Moderation 
Transfer issues between repositories. This requires Moderate role access or above on both the source and destination repository.
Hide and unhide issue comments
Lock and unlock conversation on an issue
Comment on locked issues
Managing metadata 
Create and edit issue labels
Create and edit issue milestones
Create and edit discussion categories
Check out the documentation on repository roles for more details.
