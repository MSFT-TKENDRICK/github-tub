Public monitoring is now available in public preview for GitHub Enterprise Cloud with data residency (GHEC DR).
Public monitoring with data residency 
Public monitoring extends secret scanning beyond internal repositories by monitoring public commits across github.com, attributing exposed credentials back to your enterprise in real time.
For enterprises hosted in data residency regions, attribution is powered exclusively by verified domain matching. Because data residency environments maintain strict tenant isolation from github.com, enterprise membership rosters are not shared across the boundary. Instead, when a commit author’s email matches a domain your enterprise has verified, the alert is encrypted and delivered directly to your enterprise dashboard while ensuring data stays within your designated geography.
Eligibility and billing 
Public monitoring is available in public preview for GitHub Enterprise Cloud customers with data residency. Using public monitoring requires an active GitHub Advanced Security or GitHub Secret Protection license. Enterprise admins and enterprise security managers can enable the feature under enterprise security settings.
Public monitoring is included with your GitHub Advanced Security or GitHub Secret Protection license at no additional cost.
