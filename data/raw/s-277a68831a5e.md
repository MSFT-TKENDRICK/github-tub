Copilot usage metrics now includes user-level GitHub Copilot CLI activity
As a follow-up to last week’s release of enterprise-level CLI telemetry , we’re expanding coverage to the user-level.
You can now view CLI-specific activity and usage totals in order to:
Understand which users are active CLI users to spot where enablement or support is needed.
View how many CLI requests and session counts are made to understand how developers are using Copilot day to day.
Gain visibility into token usage totals to understand consumption trends and plan for expanded rollout.
Visit our API documentation to learn more about the user-level endpoint. Join the discussion within GitHub Community .
