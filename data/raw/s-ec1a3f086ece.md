GitHub Models is no longer available to new customers
We are retiring GitHub Models. As a first step, new customers can no longer use it. If your organization or enterprise have not previously used GitHub Models, you won’t see it and can’t start new usage.
If you are an existing GitHub Models customer, nothing changes today. You can continue using the playground, API, and models as usual. We will share more details, including timelines, as we move toward full retirement.
What’s changing 
New organizations and enterprises without existing GitHub Models usage no longer have access to GitHub Models, on both free and paid plans.
Existing customers with active usage are not impacted by this change and can continue using GitHub Models for now. For new projects that need AI model access, Azure AI Foundry offers a broad model catalog.
To learn more, check out our docs about GitHub Models . You can also join our community discussions to ask questions and share feedback.
