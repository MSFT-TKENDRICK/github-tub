GitHub Models is being fully retired on July 30, 2026

What you can do 
In June, we announced that we are retiring GitHub Models and closed it to new customers. We’re now sharing the timeline for the next step: GitHub Models will be fully retired on July 30, 2026. 
After that date, GitHub Models—including the playground, model catalog, inference API, and bring your own key (BYOK)—will no longer be available to any customer. This includes existing customers with active usage.
What’s changing 
GitHub Models will be fully retired on July 30, 2026. After this date, the playground, model catalog, inference API, and BYOK endpoints will no longer be available, and the related UI will be removed.
This affects all customers. Unlike the first step in June, this change applies to everyone, including existing customers with active usage.
Brief brownouts ahead of retirement. To help you prepare, we will run short, scheduled service interruptions (brownouts) on July 16 and July 23, 2026. During a brownout, GitHub Models requests will temporarily return errors before service is restored.
What you can do 
For new and existing projects that need AI model access, Microsoft Foundry offers a broad model catalog. To build AI-powered workflows directly on GitHub, GitHub Copilot gives you access to a range of models.
To learn more, check out our docs about GitHub Models . You can also join our community discussions to ask questions and share feedback.
